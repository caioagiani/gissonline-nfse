# Schemas de serviços tomados — versão vigente

Os XSD de envio referenciam `tipos-servicos-comprados-v1_00.xsd` no
`schemaLocation`, mas o arquivo vigente publicado pelo GissOnline é o
`tipos-servicos-comprados-v1_01.xsd` — mesmo `targetNamespace`, com os campos
novos da LC 214/2025 (`piscofins`, `finNFSe`, `IBSCBS`), ausentes no v1_00.

Esta pasta traz os mesmos XSD com o v1_01 gravado sob o nome v1_00, para que a
validação local use o leiaute atual. Os arquivos originais ficam no diretório
acima, sem alteração.
